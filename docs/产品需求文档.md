# VibeFit 产品需求文档

> 版本：1.2 · 状态：在研 · 最后更新：2026-08-22
> 设计依据：`reference/综合训练计划.xlsx`（配套《训练计划-健身房三分化》《四分化肩单练版》《四分化手臂单练版》）

## 1. 产品定位

VibeFit 是一款**个人科学健身训练指导工具**，将 `reference/综合训练计划.xlsx` 中成熟的健身房分化训练方法论结构化为可执行、可记录、可追溯的训练计划与训练日志。

## 2. 训练理念

### 2.1 新手健身路径

参考文件为新手明确了上手路径：

**框架认知**：新手要先有框架，了解分化方式、各部位动作模式、配重选择等基础知识。可参考"好人松松"在 B 站发布的力训框架长视频《健身新手的完全训练手册》。

**基本动作**：健身基本动作包括推胸、夹胸、下拉、划船、推举、前平举、侧平举、反向飞鸟、弯举、臂屈伸、深蹲、硬拉等。

**上手方式**：零基础新手可以找个会练的朋友带你，或者买 20–30 节私教课，目的是能上手大部分的基本动作。接下来自己就能通过网上的动作教程视频（在 B 站抖音搜索动作名称即可）来逐步改善提高。注意这些动作视频教程不是教你上手动作的，而是在你能上手动作的情况下教你改善提高的，所以线下指导让你上手基础动作仍然是很重要的。

### 2.2 配重选择

| 配重档位 | 重复次数 | 用途                 |
| -------- | -------- | -------------------- |
| 中等配重 | 6–12 次  | 大部分时候使用       |
| 小配重   | 12–15 次 | 偶尔适应新动作时使用 |
| 大配重   | 3–5 次   | 偶尔过渡力量时使用   |

- 有自由落体砸伤危险的动作（**深蹲、卧推、推举**）**不要做到力竭**，提前 1–2 个停止以确保安全
- 其余无危险动作可以做到力竭，做不动了就放下

### 2.2 组间休息

| 部位           | 建议休息                     |
| -------------- | ---------------------------- |
| 胸 / 背 / 臀腿 | 2–3 分钟（臀腿可以更长一点） |
| 肩膀 / 手臂    | 2 分钟                       |
| 最低下限       | 不应低于 1.5 分钟            |

可自行酌调。产品在计划中按动作配置 `restSeconds`，完成一组后自动启动休息计时器。

### 2.3 分化训练原理

产品的训练日编排遵循**协同肌同日训练**原理：当主练肌群的复合动作已经会附带激活某些协同肌时，同日补练少量协同肌组数即可，无需单独安排一天。

参考文件对每个训练日都给出了协同原理说明：

| 训练日                      | 参考文件的原理说明                                                                                                                         |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 背 + 肩后束 + 肱二头        | 练背会有肩伸（肩后束）、肩水平外展（肩后束）、肘屈（肱二头肌），所以练背后接着继续用少量组数补练肩后束、肱二头即可                         |
| 胸 + 肩前中束 + 肱三头      | 练胸会有肩屈（肩前束）、肩水平内收（肩前束）、肘伸（肱三头肌），所以练胸后接着继续用少量组数补练肩前束、肱三头即可                         |
| 背 + 肱二头（肩单练版）     | 练背会有肩伸（肩后束）、肩水平外展（肩后束）、肘屈（肱二头肌），所以练背后接着继续用少量组数补练肩后束、肱二头即可（肩后束在肩日单独强化） |
| 胸 + 肱三头（肩单练版）     | 练胸会有肘伸（肱三头肌），所以练胸后接着继续用少量组数补练肱三头即可                                                                       |
| 背 + 肩后束（手臂单练版）   | 练背会有肩伸（肩后束）、肩水平外展（肩后束），所以练背后接着继续用少量组数补练肩后束即可（肱二头在手臂日单独强化）                         |
| 胸 + 肩前中束（手臂单练版） | 练胸会有肩屈（肩前束）、肩水平内收（肩前束），所以练胸后接着继续用少量组数补练肩前束即可（肱三头在手臂日单独强化）                         |

- 女性不太需要练胸大肌，每两轮三分化时，拿一轮来跳过练胸日，相当于练胸频率减半
- 腹部训练：男性要练，女性偶尔练下即可

### 2.4 三套分化方案

| **三分化**               | Day1：背 + 肩后束 + 肱二头 / Day2：胸 + 肩前中束 + 肱三头 / Day3：腿臀 + 腹 |

### 2.5 部位拆解与组数建议

#### 组数策略总结

同一部位在不同方案中组数不同，规律是：**当某部位是当日主练时组数高，作为协同肌补练时组数低**。

| 部位                      | 作为协同肌补练（三分化） | 作为主练（四分化单练版）                                              |
| ------------------------- | ------------------------ | --------------------------------------------------------------------- |
| 中胸                      | 10 组                    | 12 组                                                                 |
| 肩前束 / 肩中束           | 选 1 个 总共 5 组        | 选 1–2 个 总共 6–8 组（手臂版）/ 选 2 个 总共 8–10 组（肩单练版）     |
| 肩后束                    | 选 1–2 个 总共 6–8 组    | 选 1–2 个 总共 8–10 组（肩单练版）                                    |
| 肱二头                    | 选 1–2 个 总共 6–8 组    | 选 2 个 总共 8–10 组（手臂单练版）                                    |
| 肱三头                    | 选 1 个 总共 5 组        | 选 1–2 个 总共 6–8 组（肩单练版）/ 选 2 个 总共 8–10 组（手臂单练版） |
| 下胸 / 上胸               | 选 1 个 总共 4 组        | 同（始终为补练）                                                      |
| 背（下拉/划船）、腿臀、腹 | 选 1–2 个 总共 6–8 组    | 同（始终为主练）                                                      |

#### 腿臀循环训练

股四头肌、腘绳肌、臀大肌是三个大肌群，难以承受一次都练，按以下办法循环：

| 轮次   | 男性侧重            | 女性侧重          |
| ------ | ------------------- | ----------------- |
| 第一次 | 股四头肌 + 兼练动作 | 臀大肌 + 兼练动作 |
| 第二次 | 腘绳肌 + 兼练动作   | 腘绳肌 + 兼练动作 |

兼练动作包括：哈克机、倒蹬机、箭步蹲、史密斯深蹲。

## 3. 功能性需求

### 3.1 训练计划管理

#### FR-1.1 计划模板库

- 内置三套分化方案模板，内容与 `reference/综合训练计划.xlsx` 完全一致
- 模板按 2.7–2.11 的理念编排：训练日 → 训练阶段（肌群）→ 动作组（含"选 1–2 个动作 总共 6–8 组"等描述）→ 可选动作清单
- 用户可基于模板创建自己的计划，创建后可自由修改

#### FR-1.2 计划切换

- 同一时刻只有一个"当前激活计划"
- 切换激活计划后，"今日训练"页立即反映新计划内容
- 删除计划需二次确认

### 3.2 训练执行与记录

#### FR-2.1 训练会话

- 一次训练从"开始训练"到"结束训练"为一个**训练会话**（TrainingSession），归档到历史
- 会话状态：未开始 → 训练中 → 已暂停 → 结束
- 会话记录训练总时长（基于时间戳，暂停不累计）、开始/结束时间、所属计划/训练日快照
- 异常中断（闪退、刷新）后提供恢复选项：继续（排除中断期）/ 在最后检查点结束 / 放弃

#### FR-2.2 力量训练记录

- 每个力量动作以卡片展示：动作名、示意图、目标组数×次数、已完成组记录
- 每组记录：实际重量、实际次数、可选 RPE（1–10 主观用力程度）
- 完成"力量组"后自动启动组间休息计时器（按计划配置的休息秒数，参考 2.5）
- 支持"加练"：在目标组数之外追加一组
- 支持取消最近已完成的组（同步停止其休息计时器）
- 力量动作间切换时，休息计时器自动替换为新动作的休息秒数

#### FR-2.3 有氧训练记录

- 有氧动作独立成区，可与力量训练穿插进行
- 每个有氧器械支持：开始 → 暂停 → 继续 → 完成记录 / 取消
- 单个器械运行时独立计时（不影响整场训练总时长）
- 同一时刻最多一个有氧动作运行；开始新有氧前需完成或暂停当前有氧
- 完成时录入实际指标（依器械类型不同）：
  - **跑步机**：时长、速度（km/h）、坡度（%）、距离、热量
  - **划船机**：时长、距离、平均配速（秒/500m）
  - **椭圆机**：时长、距离、阻力等级
- 有氧训练状态在页面切换、应用重启后保持一致（不丢失计时）

#### FR-2.4 训练计时器

- **训练总计时**：从"开始训练"累计，暂停不累计，继续接续；基于时间戳，不依赖应用前台时长
- **组间休息计时**：完成力量组后启动，剩余 0 自动结束
- 暂停整场训练时清空/暂停当前休息计时器
- 结束/放弃训练时清空休息计时器

#### FR-2.5 结束训练保护

- 结束训练前若有进行中/暂停中的有氧动作，提示用户确认（防止丢失有氧数据）
- 结束时会话写入历史，包含全部力量组记录与有氧记录
- 暂停中的会话不自动归档；卡死会话需用户在恢复对话框中显式处理

### 3.3 训练历史与回顾

#### FR-3.1 历史列表

- 按日期倒序分组展示训练会话
- 每条摘要：日期、计划名、训练日名、总训练时长、力量组总数、有氧总时长
- 支持关键词搜索（动作名、计划名、笔记内容）

#### FR-3.2 详情查看

- 力量部分：每个动作的每组记录（重量、次数、RPE）
- 有氧部分：每个器械的时长、距离、速度、坡度、热量、配速等
- 总训练时长、开始/结束时间

#### FR-3.3 笔记

- 每条历史会话可附加自由文本笔记
- 笔记可在详情页编辑保存
- 笔记纳入搜索范围

### 3.4 数据管理与多端同步

#### FR-4.1 本地数据导出/导入

- 一键导出全部数据为 JSON 文件（计划 + 历史 + 设置）
- 从 JSON 文件恢复数据，导入前预览并二次确认
- 导入/导出格式在 PWA 与 Android 间完全一致，可互导

#### FR-4.2 云端备份（可选）

- 邮箱验证码登录后，可将本地全部数据作为**全量快照**上传云端
- 可从云端拉取最新一份快照恢复到本地（覆盖确认）
- 备份是全量快照模式，非增量同步；按"账号 + 设备"维度存储最新一份
- 同一账号可在 PWA 与 Android 上分别推送/拉取，后端不区分客户端类型

#### FR-4.3 数据清除

- 清除全部本地数据，需二次确认
- 生产环境走确认流程，开发环境可直连删除数据库

### 3.5 动作库

- 力量动作按参考文件的部位分类：背（下拉/划船）、肩后束、肱二头、胸（中胸/下胸/上胸）、肩前束、肩中束、肱三头、腿臀（股四头肌/腘绳肌/臀大肌/兼练动作）、腹
- 有氧器械：跑步机、椭圆机、划船机
- 每个动作标注训练的肌群（如"杠铃卧推"→ 胸 + 肱三头）
- 每个力量动作配套示意图 PNG，按 `exerciseId` 显式映射
- 有氧器械暂无示意图，UI 用品牌色块占位
- 动作库固定，用户不能自建动作，但可在计划中自由组合

## 4. 非功能性需求

### 4.1 离线优先

- 训练计划管理、训练执行、训练历史、本地数据导出/导入全部离线可用
- 无网络时仅云端备份与邮箱验证码失败，本地功能不受影响
- 训练计时基于时间戳，应用切后台/锁屏后回前台可准确接续

### 4.2 多端一致性

- PWA 与 Android App 共用同一套前端代码与数据契约
- 两端导入/导出的 JSON 格式完全一致
- 后端 API 不区分客户端类型

### 4.3 数据安全

- 不收集设备标识、不上报使用数据
- 验证码邮件仅用于登录
- 用户数据可随时导出/清除

## 5. 范围与非目标

### 5.1 当前不做

- 社交功能（关注、点赞、分享训练成果）
- 营养/饮食记录
- 体重/体脂等身体指标跟踪
- AI 教练/动作纠错/动作识别
- 付费会员/订阅
- 自动生成训练计划（计划由用户基于模板创建或自定义，产品不替用户做分化决策）

### 5.2 不为 Android 引入独立后端

- Android 与 PWA 共用同一后端 API
- Android 端原生能力（本地通知、振动、文件系统）仅作为前端能力，不改变后端契约
